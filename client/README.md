# Serene — Frontend (client)

This folder contains a Vite + React frontend scaffold for the Serene app.

Quick start (run locally):

```bash
cd client
npm install
npm run dev
```

Open http://localhost:5173

Notes:
- Tailwind is preconfigured (see `tailwind.config.js`).
- Install dependencies locally as above; this repo only contains the scaffolded files.
